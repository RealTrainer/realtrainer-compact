Splits are lines starting with `>`.

<CompactExampleBlock>
```compact
Run 8.45min 1.03km
> 1km 8'11"@140bpm
> 0.03km 0'13"@156bpm
```
</CompactExampleBlock>

Also supports pace and clock-like split duration formats.
