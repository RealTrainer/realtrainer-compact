COMPACT-formaatti ei rajoitu pelkkään harjoitteluun. Päiväkirjaan voi merkitä kaiken mikä vaikuttaa hyvinvointiin ja suorituskykyyn:

- **Ravinto** - ateriat, välipalat, proteiininsaanti, nesteytys
- **Keho** - paino, rasvaprosentti, leposyke, unenmäärä
- **Tuntemukset** - energiataso, mieliala, stressi
- **Kipu ja vammat** - lihaskireydet, nivelsäryt, toipuminen
- **Terveys** - fysioterapia, lääkitys, lääkärikäynnit
- **Talous** - treenikulut, varusteet, hieronnat
- **Muistutukset** - ostettavat tarvikkeet, varattavat ajat

Kaikki tämä data yhdistyy samaan päiväkirjaan harjoitusten kanssa, jolloin näet kokonaiskuvan palautumisesta ja edistymisestä.
