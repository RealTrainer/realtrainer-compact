Loikat ja hypyt esitetään `Contacts`-rivillä kontaktimäärillä tai `Exercise`-riveillä toistoina.

## Plyometriikka

<CompactExampleBlock>
```compact
[2026-03-01] ## Loikkaharjoitus
Section Plyometriikka
Contacts 300|Naputteluhyppelyt (päkiäkontakti)
Contacts 200|Loikat (tasamaa + ylämäki)
```
</CompactExampleBlock>

## Vauhdittomat hypyt

Räjähtävän voiman kehittäminen:

<CompactExampleBlock>
```compact
[2026-03-15] ## Voimahypyt
Tags hypyt, voima
Exercise Vauhditon pituus|10x
Exercise Vauhditon korkeus|10x
Exercise Tasatassuloikka|3x4
```
</CompactExampleBlock>
