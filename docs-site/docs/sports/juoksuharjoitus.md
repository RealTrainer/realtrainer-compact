Juoksuharjoitus esitetään `Run`-rivillä ja tarvittaessa split-riveillä sykkeillä ja paceilla.

## Peruskestävyys

<CompactExampleBlock>
```compact
[2026-03-28] ## Aamulenkki
Run 45min 8km@Z2
> 1km 5'30"@135bpm
> 1km 5'25"@138bpm
```
</CompactExampleBlock>

## Koordinaatiojuoksu

Tekniikkapainotteinen lämmittely:

<CompactExampleBlock>
```compact
[2026-02-23] ## Koordinaatiot
Section Lämmittely
Run 30min@easy | Rauhallinen lenkki
Section Tekniikka
Run "polvennostojuoksu" 6x20m/1min
Run "pakaraanlyöntijuoksu" 4x30m/1min
```
</CompactExampleBlock>

## Maastolenkki

Polkujuoksu vaihtelevassa maastossa:

<CompactExampleBlock>
```compact
[2026-04-05] ## Polkulenkki
Tags polkujuoksu, maasto
Run 60min 10km@Z2-Z3
> 5km 28min | Ylämäkiosuus
> 5km 25min | Alamäki
```
</CompactExampleBlock>

## Ylämäkijuoksu

Voimakestävyyttä kehittävä harjoitus:

<CompactExampleBlock>
```compact
[2026-03-15] ## Ylämäet
Section Lämmittely
Run 15min@easy
Section Pääosa
Run 3x120m@50%/kävely | Juoksuasennon haku
Run 3x50m@90%/2min | Ylämäki
Section Jäähdyttely
Run 10min@easy
```
</CompactExampleBlock>
