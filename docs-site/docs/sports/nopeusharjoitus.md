Nopeusharjoitus kuvataan vedoilla: `Run` tai `Interval` intensiteetillä ja palautuksilla.

## Kiihdytykset

<CompactExampleBlock>
```compact
[2026-03-11] ## Kiihdytykset
Section Nopeus
Run 3x60m@95%/2min | Kiihdytykset
Run 4x40m@max/3min | Maksimaalinen
```
</CompactExampleBlock>

## Askellukset (hallissa)

Tekniikka ja nopeuskestävyys:

<CompactExampleBlock>
```compact
[2026-02-24] ## Hallinopeus
Tags nopeus, halli
Section Koordinaatio
Run "polvennostojuoksu" 3x30m
Run "marssi" 3x30m
Run "kuopaisuhyppely" 3x30m
Section Askellukset
Run 6x60m@90%/2min
```
</CompactExampleBlock>

## Vastusvedot

Voimanopeuden kehittäminen:

[2026-03-20] ## Vastusharjoitus

Section Vapaat vedot
Run 3x50m@95%/3min

</CompactExampleBlock>
