# React Components

This page demonstrates the `realtrainer-compact/ui` export,
which provides ready-to-use React components for rendering COMPACT data.

[Open the live React playground](https://realtrainer.github.io/realtrainer-compact/compact-ui/)

The current Vite gallery mirrors the exported API surface closely:
- `CompactView` for parser-first full rendering
- `CompactRowView` for one generic row entry point
- direct row exports like `Phase`, `MoveRow`, `Duration`, `SplitRow`, and `Unknown` when you want a smaller rendering surface

---

## Installation

```bash
npm install realtrainer-compact react react-dom
```

Import the CSS in your app entry point:

```tsx
import 'realtrainer-compact/ui/styles.css';
```

## Exercise Row

**COMPACT syntax:**
```compact
Exercise Takakyykky|3x8@100kg|Lämmittelysarjat erikseen
```

**React component:**
```tsx
import { Exercise } from 'realtrainer-compact/ui';
import type { CompactExerciseRow } from 'realtrainer-compact/ui';

const exercise: CompactExerciseRow = {
  id: 'ex-1',
  type: 'exercise',
  name: 'Takakyykky',
  sets: 3,
  reps: 8,
  weightKg: 100,
  note: 'Lämmittelysarjat erikseen',
};

<Exercise row={exercise} />
```

## CompactView

`CompactView` is the parser-first entry point when you do not want to build a custom `CompactWorkoutModel` yourself.
It accepts raw COMPACT text, `parseCompact(...)` results, a parsed `Document`, a parsed `Workout`, or an already prepared UI workout model.

**React component with raw COMPACT text:**
```tsx
import { CompactView } from 'realtrainer-compact/ui';

const compact = `
[2026-04-11]
## Voimaharjoitus
Tags voima, jalat
Exercise Takakyykky|3x8@100kg
Run 8km | Peruskestävyysalueella
`;

<CompactView data={compact} showHeader />
```

**React component with parser result:**
```tsx
import { parseCompact } from 'realtrainer-compact';
import { CompactView } from 'realtrainer-compact/ui';

const parsed = parseCompact(compact);

<CompactView data={parsed} showHeader />
```

## Row-level Components

If you already know the row type, you can import the row renderer directly instead of routing everything through `CompactRowView`.

```tsx
import {
  Phase,
  Section,
  Custom,
  Exercise,
  PyramidRow,
  MoveRow,
  Run,
  Duration,
  SplitRow,
  Text,
  Unknown,
} from 'realtrainer-compact/ui';
```

Use this when:
- you already have a typed row and want the smallest possible rendering surface
- you want per-row demos or tests without the generic dispatcher
- you want your UI code to match the parser row type more explicitly

Keep using `CompactRowView` when:
- the input may be any row type
- you want one generic row entry point
- you are passing parser-native `Content` values around and do not want a manual switch nearby

## TypeScript Types

The package exports all necessary TypeScript interfaces:

```ts
import type { Content } from 'realtrainer-compact';
import type {
  CompactRenderableData,
  CompactRowInput,
  CompactRowViewProps,
  CompactViewProps,
  CompactWorkoutModel,
  CompactRow,
  CompactExerciseRow,
  CompactPyramidRow,
  CompactPyramidSet,
  CompactMoveRow,
  CompactRunRow,
  CompactDurationRow,
  CompactSplitRow,
  CompactSectionRow,
  CompactPhaseRow,
  CompactSummaryRow,
  CompactTextRow,
  CompactUnknownRow,
} from 'realtrainer-compact/ui';

import {
  CompactRowView,
  CompactView,
  Summary,
  Phase,
  Section,
  Custom,
  Exercise,
  PyramidRow,
  MoveRow,
  Run,
  Duration,
  SplitRow,
  Text,
  Unknown,
} from 'realtrainer-compact/ui';
```

- `CompactRowInput` is the practical row input type for row-level rendering: `CompactRow | Content`.
- `CompactRenderableData` is the parser-first union used by `CompactView`.
- Row-level components such as `Phase`, `MoveRow`, and `Duration` are exported directly when you want a smaller surface than `CompactRowView`.
- The Vite gallery groups these direct row exports under their own sidebar section so you can inspect each renderer separately.

## Component Props

Current public props used by the React UI package.

### `CompactRowView`

```ts
type CompactRowViewProps = {
  row: CompactRowInput;
};
```

- `row`: One parser-native `Content` row or one normalized UI `CompactRow`. This is the main read-only row renderer.

### `CompactBlogView`

```ts
type RowInteractionEvent = 'click' | 'press' | 'hover';

interface CompactBlogHeaderOptions {
  showTitle?: boolean;
  showDate?: boolean;
  showTags?: boolean;
  showEmojis?: boolean;
  showPoints?: boolean;
  showMetaStrip?: boolean;
}

type CompactBlogViewProps = {
  workout: CompactWorkoutModel;
  onRowInteraction?: (rowId: string, event: RowInteractionEvent) => void;
  showHeader?: boolean;
  headerOptions?: CompactBlogHeaderOptions;
};
```

- `workout`: Full workout card model to render.
- `onRowInteraction`: Optional row-level interaction callback. When provided, rows become keyboard/click interactive and emit `click`, `press`, or `hover`.
- `showHeader`: Controls whether the top workout header is shown. Default is `true`.
- `headerOptions`: Fine-grained visibility toggles for header content and metadata strip.

### `CompactView`

```ts
type CompactRenderableData =
  | string
  | ParseResult
  | ParseFailure
  | Document
  | Workout
  | CompactWorkoutModel
  | CompactWorkoutModel[];

type CompactViewProps = {
  data: CompactRenderableData;
  workoutIndex?: number;
  showHeader?: boolean;
  headerOptions?: CompactBlogHeaderOptions;
  onRowInteraction?: (rowId: string, event: RowInteractionEvent) => void;
  renderers?: CompactUiRenderers;
  emptyState?: ReactNode;
  errorFallback?: (message: string) => ReactNode;
};
```

- `data`: The main parser-first input. Pass COMPACT text, parser output, a parsed workout, or a ready-made UI model.
- `workoutIndex`: Optional index when `data` contains multiple workouts and you want to render only one.
- `showHeader`: Same header visibility control as `CompactBlogView`.
- `headerOptions`: Same fine-grained header controls as `CompactBlogView`.
- `emptyState`: Optional fallback when no workouts are available.
- `errorFallback`: Optional custom renderer for parse errors.

### `CompactBlogHeaderOptions`

- `showTitle`: Show or hide the workout title.
- `showDate`: Show or hide the workout date.
- `showTags`: Show or hide tags.
- `showEmojis`: Show or hide emojis.
- `showPoints`: Show or hide points badge.
- `showMetaStrip`: Force the separate metadata strip below the header. Useful when `showHeader={false}`.

Example:

```tsx
<CompactBlogView
  workout={workout}
  headerOptions={{
    showTags: true,
    showEmojis: true,
    showPoints: true,
  }}
/>
```

### `CompactBlogEditor`

```ts
type CompactBlogEditorProps = {
  workout: CompactWorkoutModel;
  onChange: (next: CompactWorkoutModel) => void;
};
```

- `workout`: Editable workout model.
- `onChange`: Called whenever header fields or any row editor changes the workout.

## Using with Parser

Parse COMPACT text and render directly:

```tsx
import { parseCompact } from 'realtrainer-compact';
import { CompactView } from 'realtrainer-compact/ui';

const text = `
[2026-04-11]
## Aamuharjoitus
Exercise Kyykky|3x10@80kg
`;

const parsed = parseCompact(text);

<CompactView data={parsed} showHeader />
```

See [Vite Playground](https://github.com/RealTrainer/realtrainer-compact/tree/main/ui/react) 
for complete parser-to-UI integration example.
