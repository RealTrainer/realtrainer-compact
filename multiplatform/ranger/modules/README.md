# Ranger Parser Modules (Generated Artifacts)

This folder is meant for version-controlled parser module snapshots that can be reused from other projects.

Targets included:
- JavaScript
- TypeScript
- Swift
- Kotlin

Active variant:
- `ng` (new NG parser)

## How to regenerate

From repository root:

```bash
npm run ranger:modules:build
```

This runs target builds and then exports generated parser files into this folder.

## Folder layout

- `js/ng/`
- `ts/ng/` (native Ranger TypeScript output)
- `swift/ng/`
- `swift/common/` (compatibility shims)
- `kotlin/ng/`
- `kotlin/common/` (JSON shim)

`BUILD_INFO.json` is autogenerated on each export and contains copied files and sizes.
